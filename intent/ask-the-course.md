# Intent: Ask the Course (RAG Assistant)

## Purpose
A local Retrieval-Augmented Generation (RAG) tool that indexes course materials from a local clone of the course repository and answers student inquiries with exact context chunks and scores.

## Target Audience
Students and course staff seeking rapid, grounded answers to curriculum questions.

## Core Commitments
1. Answers must be derived strictly from retrieved course markdown/text chunks.
2. If content cannot be found in the index, the program must return "I can not find that."
3. No API keys or credentials stored in git.
